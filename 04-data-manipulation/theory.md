# Урок 1: Добавление данных, оператор INSERT

Источник:  
[Добавление данных, оператор INSERT – SQL-Academy](https://sql-academy.org/ru/guide/operator-insert)

---

`INSERT` добавляет новые записи в таблицу через `VALUES` и через `SELECT`.

```sql
INSERT INTO имя_таблицы [(поле1, поле2, ...)]
VALUES (значение1, значение2, ...)
| SELECT поле1, поле2, ...
  FROM другая_таблица;
```

- Если указаны поля, значения в `VALUES` должны идти в том же порядке.
- Количество значений должно совпадать с количеством полей.
- Если поле не указано, оно получит значение по умолчанию или `NULL`, если это разрешено.

---

- `INSERT INTO ... VALUES` — для готовых значений.
- `INSERT INTO ... SELECT` — для данных из запроса.
- Список полей лучше указывать всегда.
- `AUTO_INCREMENT` удобнее ручного выбора `id`.
