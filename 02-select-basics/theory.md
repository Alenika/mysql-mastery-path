# 📖 Модуль 2. Основы выборки I

## Урок 1. Базовый синтаксис SELECT

**Шаблон запроса:**
```sql
SELECT column_list
FROM table_name;
```
**4 примера:**

1. **Произвольная строка:**
```sql
SELECT 'Hello world';
```

2. **Все колонки таблицы:**
```sql
SELECT *
FROM FamilyMembers;
```

3. **Конкретные колонки:**
```sql
SELECT 
    member_id, 
    member_name 
FROM FamilyMembers;
```

4. **С псевдонимом (AS):**
```sql
SELECT 
    member_name AS Name
FROM FamilyMembers;
```

## Урок 2. Литералы в SQL

**Литерал** = фиксированное значение в запросе (число `12`, строка `'SQL'`)

### Типы литералов

| Тип | Пример |
|-----|--------|
| Строка | `'Hello world'` |
| Число | `42`, `3.14`, `1e3` |
| Логический | `TRUE`, `FALSE` (= 1, 0) |
| NULL | `NULL` ("нет данных") |
| Дата | `'2026-01-25'` |

## Урок 3. Применение функций

**Функция** = встроенный код СУБД для преобразования данных.

**Принцип:** функция(аргументы) → литерал

### Популярные функции

| Функция | Что делает | Пример |
|---------|------------|--------|
| `UPPER('hello')` | Верхний регистр | `'HELLO'` |
| `LOWER('SQL')` | Нижний регистр | `'sql'` |
| `LENGTH('sql')` | Длина строки | `3` |
| `YEAR('2026-01-25')` | Год из даты | `2026` |
| `INSTR('abcde', 'cd')` | Позиция подстроки | `3` |

## Урок 4. Исключение дубликатов, DISTINCT

**DISTINCT** – убрать дубликаты строк, оставить только уникальные.

```sql
SELECT [DISTINCT] поля_таблиц
FROM наименование_таблицы;
```

**Важно:** строка считается дубликатом, только если совпадают все выбранные поля.

## Урок 6. Операторы IS NULL, BETWEEN, IN

### 1. IS NULL / IS NOT NULL
Используются для работы с "пустотой" (**NULL**).  
Нельзя использовать `=` для сравнения с NULL.  

* **`IS NULL`** — выбирает записи, где значение отсутствует.

```sql
SELECT *
FROM Teacher
WHERE middle_name IS NULL;
```

* **`IS NOT NULL`** — выбирает записи, где поле заполнено.

```sql
SELECT *
FROM Teacher
WHERE middle_name IS NOT NULL;
```

### 2. BETWEEN

Проверяет вхождение значения в указанный диапазон включая границы.

```sql
SELECT *
FROM Payments
WHERE unit_price BETWEEN 100 AND 500;
```

### 3. IN

Проверяет, соответствует ли значение хотя бы одному элементу из заданного списка.

```sql
SELECT *
FROM FamilyMembers
WHERE status IN ('father', 'mother');
```

## Урок 7. Оператор LIKE

Оператор **LIKE** используется при условных запросах для поиска строк по **шаблону**.

```sql
WHERE поле LIKE 'шаблон'
WHERE поле NOT LIKE 'шаблон'
```

**Специальные символы:**

- `%`	любое количество символов (0 и более)
- `_`	ровно один любой символ

**ESCAPE** — экранирование `%` и `_`

---

## Урок 8. Оператор REGEXP (регулярные выражения)

**REGEXP** — мощный поиск по сложным шаблонам строк (замена LIKE для сложных случаев) (синоним: RLIKE).

```sql
... WHERE table_field REGEXP 'pattern';
```

## Урок 9. Сортировка, оператор ORDER BY

**ORDER BY** задаёт порядок строк в результате (по умолчанию — случайный).

```sql
SELECT поля_таблиц FROM наименование_таблицы
WHERE ...
ORDER BY столбец_1 [ASC | DESC][, столбец_n [ASC | DESC]]
```

**ASC** — по возрастанию (по умолчанию)
**DESC** — по убыванию

---

## Урок 10. Группировка GROUP BY

**GROUP BY** разбивает строки на группы по одинаковым значениям столбца.

**Можно выводить только:**
- поля группировки
- агрегатные функции (AVG, COUNT, SUM...)
- литералы

```sql
SELECT [литералы, агрегатные_функции, поля_группировки]
FROM имя_таблицы
GROUP BY поля_группировки;
```

---

## Урок 11. Агрегатные функции

**Агрегатные функции** вычисляют значение по **группе** строк (SUM, AVG, COUNT, MIN, MAX).

Работают **только** с `GROUP BY` или по всей таблице.

```sql
SELECT [литералы, агрегатные_функции, поля_группировки]
FROM имя_таблицы
GROUP BY поля_группировки;
```

---

## Урок 12. Оператор HAVING

**HAVING** фильтрует **группы** после `GROUP BY` (WHERE фильтрует строки до группировки).

```sql
SELECT [константы, агрегатные_функции, поля_группировки]
FROM имя_таблицы
WHERE условия_на_ограничения_строк
GROUP BY поля_группировки
HAVING условие_на_ограничение_строк_после_группировки
ORDER BY условие_сортировки
```

**Порядок выполнения:**
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

### WHERE vs HAVING: ключевые различия

| Критерий | WHERE | HAVING |
|----------|-------|--------|
| **Когда применяется** | До группировки | После группировки |
| **Что фильтрует** | Отдельные строки | Группы строк |
| **Можно использовать агрегатные функции** | ❌ Нет | ✅ Да |
| **Производительность** | Быстрее (меньше данных для группировки) | Медленнее (группирует все, потом фильтрует) |

### Правила использования HAVING

В условии `HAVING` можно использовать только:

✅ **Агрегатные функции**: `COUNT()`, `SUM()`, `AVG()`, `MAX()`, `MIN()`  
✅ **Поля из GROUP BY**: колонки, по которым происходит группировка  
✅ **Константы**: конкретные значения  

❌ **Нельзя использовать**: поля, которые не участвуют в GROUP BY и не обернуты в агрегатную функцию
